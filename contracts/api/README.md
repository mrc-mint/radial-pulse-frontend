# Published API contract

`openapi.json` is a pinned snapshot of a **published, tagged** version of the
platform API contract (OpenAPI, generated by FastAPI in the backend repo and
attached to a GitHub release by backend CI). `VERSION` records which one.

- Change it only with `pnpm api:sync --version <x.y.z>`, in its own PR.
- CI regenerates `packages/shared-types/src/contract/generated.ts` from the
  snapshot and fails on any difference (`pnpm contract:check`).
- The frontend consumes only this API contract. Engine data contracts between
  domain engines and the platform are backend-internal.

No contract has been published yet (`VERSION` is `none`).
